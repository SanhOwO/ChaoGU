## 一、A 股全数据数据库

| 属性 | 值 |
|------|-----|
| **路径** | `AlphaGPT/data_pipeline/ashare_data.db` |
| **大小** | 721 MB |
| **格式** | SQLite |
| **记录数** | 5,174,803 条 |
| **股票数** | 3,657 只 |
| **日期范围** | 2020-01-02 ~ 2026-07-10 |
| **表名** | `daily_kline` |
| **列** | `date, code, open, high, low, close, volume, amount, turnover, circulating_market_cap` |
| **数据来源** | `数据/all_stock_cache.csv`（本地 CSV） |

### 数据来源说明

- CSV 文件由用户提供，包含 date, open, high, low, close, volume, symbol（去前导零股票代码）
- 通过 `csv_to_db.py` 导入 SQLite，symbol 补全为 6 位标准代码
- `amount` = close × volume（元）
- `turnover` 和 `circulating_market_cap` 当前为 0（AKShare 网络受限，后续可补充）

## 三、核心改动点

### 3.1 数据层：Birdeye → 本地 CSV / AKShare

| 维度 | 原版 | A 股版 |
|------|------|--------|
| **数据源** | Birdeye API（付费） | `数据/all_stock_cache.csv`（本地）+ AKShare（备用） |
| **数据库** | Postgres + TimescaleDB | SQLite（简化部署） |
| **数据格式** | 链上代币 OHLCV | A 股日 K 前复权数据 |
| **导入方式** | 实时 API 拉取 | `csv_to_db.py` 一次性导入 |
| **API Key** | 需要 Birdeye Key | **无需任何 Key**（CSV 本地） |

### 3.2 因子层：Meme 币 → A 股 12 维

| 因子 | 原版（6维） | A 股版（12维） | 计算方式 |
|------|------------|---------------|----------|
| `RET` | ✅ | ✅ | log(close_t / close_{t-1}) |
| `LIQ_SCORE` | ✅ | ❌ | 流动性/FDV（A 股无此概念） |
| `PRESSURE` | ✅ | ❌ | 买卖力量不平衡 |
| `FOMO` | ✅ | ❌ | 成交量加速度 |
| `DEV` | ✅ | ✅ | 偏离 20 日均线 |
| `LOG_VOL` | ✅ | ❌ | 对数成交量 |
| `TURN` | ❌ | ✅ | 换手率标准化 |
| `VOLAT` | ❌ | ✅ | 20日波动率 |
| `MOM` | ❌ | ✅ | 20日动量 |
| `LOG_AMT` | ❌ | ✅ | 对数成交额 |
| `RSI` | ❌ | ✅ | 14日 RSI |
| `VR` | ❌ | ✅ | 量比 |
| `LOG_MC` | ❌ | ✅ | 对数流通市值 |
| `HL_RANGE` | ❌ | ✅ | 振幅 |
| `CLOSE_POS` | ❌ | ✅ | 收盘在区间位置 |
| `MACD_HIST` | ❌ | ✅ | MACD 柱状图 |

### 3.3 回测层：DEX 即时成交 → A 股 T+1

| 规则 | 原版 | A 股版 |
|------|------|--------|
| **成交时机** | 即时（链上 DEX） | T 日信号 → T+1 日开盘成交 |
| **买入成本** | 0.6%（Swap+Gas+Jito） | 0.025% 佣金 |
| **卖出成本** | 0.6% | 0.025% 佣金 + 0.05% 印花税 |
| **最低佣金** | 无 | 5 元 |
| **滑点** | trade_size / liquidity | 0.1% 固定 |
| **涨跌停** | 无 | 涨停不能买入，跌停不能卖出 |
| **目标收益** | open_{t+2} / open_{t+1} | 同上（T+1 开盘 → T+2 开盘） |

### 3.4 交易层：自动链上执行 → 人工操作

| 维度 | 原版 | A 股版 |
|------|------|--------|
| **执行方式** | 自动调用 Jupiter 下单 | **人工查看报告后决策** |
| **钱包** | Solana 私钥 | 无（人工通过券商交易） |
| **风控** | 流动性 + Honeypot | 涨跌停 + 成交额过滤 |
| **输出** | 链上交易确认 | `daily_report_YYYY-MM-DD.txt` |
| **报告内容** | 无 | Top 买入/回避信号 + 因子值 + 统计 |

### 3.5 模型层：完全保留

| 设计 | 状态 | 说明 |
|------|------|------|
| Transformer 公式生成 | ✅ 保留 | 自回归生成 token 序列 |
| StackVM 执行 | ✅ 保留 | 栈式虚拟机执行因子公式 |
| REINFORCE 强化学习 | ✅ 保留 | 策略梯度训练 |
| Looped Transformer | ✅ 保留 | 层内循环 3 次 |
| Newton-Schulz LoRD | ✅ 保留 | 低秩正则化 |
| QKNorm | ✅ 保留 | Query-Key 归一化 |
| Median+MAD 归一化 | ✅ 保留 | 鲁棒统计归一化 |
| 四层解耦架构 | ✅ 保留 | 数据/模型/策略/执行 |

## 四、使用流程

```
Step 1: 数据导入（已执行）
    python csv_to_db.py
    → 生成 data_pipeline/ashare_data.db（721MB）

Step 2: （可选）补充市值数据
    python supplement_data.py
    → 从 AKShare 获取 turnover + market_cap

Step 3: 训练模型
    python daily_runner.py --mode train
    → 生成 best_meme_strategy.json（最优公式）

Step 4: 每日信号（T 日收盘后）
    python daily_runner.py --mode signal
    → 生成 daily_report_YYYY-MM-DD.txt + .csv

Step 5: T+1 日人工操作
    阅读报告 → 券商下单
```
